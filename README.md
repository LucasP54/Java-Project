## Descripción

Este proyecto consiste en un juego hecho en Java en el que tienes que gestionar tu propia tienda de videojuegos. Tendrás que comprar juegos, poner precios y atender a los clientes para ganar dinero.

## Objetivo del juego

Empiezas con 1.000 euros.
Tienes 15 días para conseguir 2.500 euros.
Si te quedas sin dinero, pierdes la partida.
Si consigues llegar a los 2.500 euros, ganas.

## Opciones del menú

1.Comprar videojuegos: comprar más unidades para la tienda.
2.Cambiar precios: modificar el precio de venta de los juegos.
3.Atender clientes: recibir a los clientes y vender videojuegos.
4.Estadísticas: consultar ingresos, gastos y beneficios.
5.Pasar de día: avanzar al siguiente día.
6.Inventario: ver los juegos y las unidades disponibles.
7.Salir: terminar la partida.

## Funcionamiento

La tienda empieza con 5 videojuegos diferentes.
Cada día aparecen 3 clientes.
Cada cliente quiere un juego diferente y tiene un presupuesto aleatorio.
Para vender un juego, tiene que haber unidades disponibles y el precio debe estar dentro del presupuesto del cliente.
Solo se puede atender a los clientes una vez por día.
Puedes comprar más unidades cuando quieras, siempre que tengas dinero suficiente.

## Herramientas utilizadas

Java como lenguaje de programación.
Visual Studio Code para escribir el código.
Scanner para introducir datos.
Arrays para guardar los juegos, precios y existencias.
Bucles, condicionales y switch para el funcionamiento del juego.
